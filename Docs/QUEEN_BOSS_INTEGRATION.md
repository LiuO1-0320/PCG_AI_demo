# 女王 Boss 接入 demo

以 `ACastleEnemy` 为基础新增 `ACastleQueen`，只在 `ACastleDirector::AddEnemy(..., true)` 时使用；普通敌人继续使用原类。保留 `BT_CastleBoss`、黑板、Recast 导航、随机楼梯与柱子、传送、楼层成长和击杀解锁流程。没有迁入 boss1 的测试地图、玩家或 GameMode，也没有修改其源工程。

## 已迁入

- `Content/BossPrototype/QueenDemo`：女王骨骼模型、原始底色贴图、身体与画框材质、射击与地面施法动画，以及骨架等依赖。
- `Content/BossPrototype/Materials`：双炮核心、光晕及地面预警材质。共 11 个迁入资产包，约 7.6 MB，使用 Git LFS 管理。
- 女王显示高度约 300 cm。保持 demo 的移动胶囊和寻路方式，另外添加只参与射线查询的上半身命中范围，避免身高变化导致上半身无法被射击。
- 两个发射点跟随 `weapon_l`、`weapon_r` 骨骼。0.7 秒射击前摇、聚能光核和局部补光，发射后短闪、弹体光晕与短尾迹。常态每侧 3 发，半血后每侧 5 发。
- 地面技能 1.4 秒前摇、280 cm 半径，绑定玩家实际站立地面。地面施法清理本女王旧弹体，不和双炮同时起手，并保留恢复间隔。
- 半血触发一次 2 秒阶段切换，停止移动，清理弹体和预警，期间不受伤，随后提高弹幕数量与频率。

## 与 boss1 的有意区别

移动继续采用 demo 的 `MoveToActor` 导航追击，没有移入 boss1 的局部扫掠后撤/横移。生命与伤害保持 demo 楼层成长：第二层生命 775、弹体伤害 22，第三层生命 1050、弹体伤害 26；地面伤害为弹体伤害的 2.4 倍。地面技继续保留 demo 不依赖视线的行为，并在已起手后超出决策距离时正常结算。

同一女王的弹体对玩家有 0.12 秒受伤间隔，避免两门炮的中央弹同帧叠伤。死亡、换层和玩家死亡时会清理旧攻击。没有新增未提供的行走、死亡或受击动画。

## 材质修复

初次迁入的骨骼资产材质槽仍指向 WorldGrid 默认材质，导致模型接近纯色。`Scripts/PrepareQueenAssets.py` 已重新绑定底色贴图、身体和画框材质并保存、编译；运行时也显式绑定各槽，再为画框创建动态材质。实机近景已确认面部、服装及画框纹理恢复。
