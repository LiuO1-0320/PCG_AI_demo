# 空寂古堡：主探索区的环境设计

主角曾是宫廷画师。玩家进入城堡时，应该先认出一座曾经有人居住的王宫，再发现画框还在、画中人却不见了。设计依据是《pcg&AI 背景故事初稿及制作分工》第 1、3 页。

| 玩家会看到什么 | 读到的信息 |
| --- | --- |
| 入口的穹顶、酒红挂旗和地面罗盘。挂旗上有交叉的画笔 | 这里曾属于宫廷，也和主角的职业有关系。 |
| 普通战斗房的壁烛、残破的镀金框和撕裂的无面肖像 | 边框掉在墙脚，画布的裂口露出石墙。暗处仍能辨认墙、掩体和门洞。 |
| 石门和有拱顶的短走廊 | 较低的走廊把通路和高大的房间区分开。三层探索区的室内拱顶分别约高 10.3、11.0 和 11.7 米。 |
| 商店的铁砧和手锤；休息房的卷毯、行包和暖灯 | 即使不读房名，也能区分升级和补给两种用途。 |
| 记忆宝箱房里的无面肖像和淡紫光 | 与其他房间的空画框形成对照，提示这里有过去留下的东西。 |

## 和地图生成的关系

PCG 先确定房间、相邻关系、门洞与奖励，再用同一种子派生的一组独立随机数决定地砖转向等外观。房间原来的门洞继续用于通行。穹顶和上层墙体可以挡弹，暗处悬挂的画框和其他小装饰不参与碰撞。

## 在编辑器里查看

打开 `testfordemo.uproject` 后点击播放。开场菜单背后预览种子 `1337` 的室内入口。可以沿用这个种子或填写其他种子。先从补给匣看向入口的挂旗、无面肖像和穹顶，再比较普通战斗房和休息房的光线。枪械模型来自 Kenney，详见 [素材和许可](../SourceArt/CastleCarbine/README.md)。
